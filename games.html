FROG JUMPER RUSH

Role: Lead Developer. Stack: Unity, C#, Aseprite

Released in 2025 on App Store and Google Play

Swing, hop, and munch your way up endless woods in this quirky mobile vertical runner! On your mobile device, guide a frog with charged jumps and a stretchy tongue to stick to ever-changing platforms, dodge deadly spiked and burning platforms and poisonous snakes, and gobble crickets to open stylish hats. Master procedurally generated levels for a fresh, reflex-testing challenge every run!

PIXEL BRAWL

Role: Developer. Stack: Unity, C#, Shader Graph

Academic Project, 2025

Academic project for my Game Programming course at Centennial College. A roguelite shooter inspired by classics like The Binding of Isaac and Enter the Gungeon. Players battle enemies in randomly generated rooms. My teammates and I worked for 3 months on this PC game using Unity.

- Implemented player controller using new Unity's Input System with Gamepad and Keyboard/Mouse support.
- Implemented Gamepad and Keyboard/Mouse UI Navigation support.
- Implemented procedural map generation.
- Used Unity Internationalization System for 7 languages.
- Designed AI using Unity's Behavior System.
- Used Shader Graph for health feedback.
- Implemented mechanics such as move, shoot, parry, and dash with invincibility frames.
- Developed Debug Mode for testing all features.
- Structured the project in modules using Assembly Definition.
- Wrote Play/Edit Mode automated tests.
